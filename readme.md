# mmarrder: Data Analyst Toolbox 📊

Librería personalizada de Python diseñada para estandarizar procesos de **Extracción, Transformación, Carga (ETL)** y generación de reportes paramétricos.

## 🚀 Instalación

Puedes instalar esta librería directamente desde GitHub usando `pip`:

```bash
pip install git+[https://github.com/TU_USUARIO/mmarrder.git](https://github.com/TU_USUARIO/mmarrder.git)
